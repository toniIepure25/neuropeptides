# ntx v0.18.0

Research-grade hardening, a machine-readable API contract, a documentation site
and an attested release path.

## Highlights

- **OpenAPI 3.1 contract.** `GET /api/v1/openapi.json` documents every read-only
  route, parameter, response and security scheme. CI compares it with the server
  route table.
- **Documentation site.** A strict MkDocs Material site with command reference,
  architecture, method, evaluation protocol, limitations and API documentation is
  deployed to GitHub Pages.
- **Property tests.** Fixed-seed tests exercise redaction/hydration round-trips,
  hash tampering, invalid spans and non-mutating redaction.
- **Supply chain.** CodeQL, dependency review, OpenSSF Scorecard, a CycloneDX
  SBOM, SHA-256 checksums and GitHub build-provenance attestations.
- **Repository hygiene.** Governance, roadmap, support, maintainers, CODEOWNERS,
  Dependabot grouping and branch/tag protection.

## Compatibility

- Python 3.11–3.13.
- Database schema v8, report schema v4, quality payload v2, ledger export v3.
- Annotation schema v2; no migration and no data-format break.
- Runtime remains Python standard library only. Documentation and release
  tooling are optional development extras.

## Known limitations

There is no human-validated gold set and no DOI yet. Effect sizes are heuristic
and not pooled. This is research software, not a clinical decision tool.
