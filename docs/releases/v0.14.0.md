# ntx v0.14.0 - 2026-11-16

Claim-level reconciliation between abstracts and open-access full text. The
default abstract pipeline and its reports are unchanged; the full-text comparison
becomes inspectable per entity/outcome instead of a set of document counters.

## Highlights

- **Grouped findings, not tuple counters.** `ntx fulltext report` groups stored
  claims by `(doc_id, entity_id, outcome)` and assigns `corroborated`,
  `direction_conflict`, `abstract_only`, `fulltext_only` or `indeterminate`.
- **Explicit reasons.** Findings can carry `direction_conflict`,
  `significance_conflict`, `sample_size_discrepancy`, `hedging_mismatch`,
  `discussion_only`, `abstract_sentence_in_fulltext` and `mixed_directions`.
  High severity is limited to direction/significance conflicts; sample size is
  medium; hedging, discussion-only, echoed sentences and mixed directions are low.
- **Evidence structure.** Each finding keeps up to five exact-span references per
  side, full claim counts, section counts, retraction status and document metadata.
  The report is deterministic through a canonical content hash that excludes
  `generated_at`.
- **Filters and thresholds.** `--entity NP:OXT` narrows the report and
  `--fail-on {none,low,medium,high}` turns severity into an exit code.
  `--fail-on-conflict` remains as an alias.
- **Optional brief section.** `ntx report --with-fulltext` adds reconciliation to
  Markdown and HTML briefs, including an explicit note when an entity has no
  reconcilable groups. Default `ntx report` output is byte-identical to v0.13.
- **Integrity.** The report checks abstract and full-text provenance before
  building. A full-text defect blocks `--with-fulltext` but not the default brief.
- **No redistribution.** Full text remains local database/cache state only. It is
  never committed, packaged or published.

## Commands

```powershell
ntx fulltext report --db build/demo.db --json --out reports/fulltext.json
ntx fulltext report --db build/demo.db --entity NP:OXT --fail-on high
ntx fulltext report --db build/demo.db --fail-on-conflict
ntx report --db build/demo.db --out reports/fulltext-aware --with-fulltext
```

## Limits

- Only PMC open-access JATS; no publisher PDFs, supplementary files or
  comprehensive figure/table cell extraction.
- Grouping is claim-level and section-aware but does not perform semantic
  equivalence, effect-size pooling or full article validation.
- `corroborated` means the stored layers share a direction; it is not proof that
  the abstract is correct or that the study is valid.
- `abstract_sentence_in_fulltext` is an exact normalized phrase match, not a
  plagiarism or abstract-fidelity detector.
- Full-text claims are not promoted automatically into the default briefs,
  discovery, calibration or the ledger.
- Papers without a PMCID or available body remain outside the full-text layer.
