# ntx v0.3.0 — 2026-11-13

Model v3 / extraction v2, evidence synthesis, paired ablations and a read-only
local API. Rules-only core: no model downloads, no network in the default path.

## Highlights

- **Clause-scoped claims.** Direction is read from the clause containing the
  entity, with role (`intervention`/`comparator`/`mechanism`), abstract section,
  an evidence span and explicit confidence reasons. One sentence can yield
  several claims.
- **Schema v3** with idempotent migration from v1/v2. Provenance now also checks
  the evidence span against the sentence.
- **`ntx synthesize`** — design-weighted per entity/outcome summary, human/animal
  split, document-level bootstrap interval and a `fragile` flag. Comparator
  claims excluded by default.
- **`ntx ablate`** — paired feature-flag ablation with delta-F1 intervals;
  refuses provenance failures and reports gold documents missing from the corpus.
- **`ntx serve`** — read-only JSON API on `127.0.0.1` with paged claims, gaps,
  synthesis and latest manifest; SQLite opened read-only.
- **`ntx.toml`** — typed settings with CLI > environment > file > default
  precedence; `ntx config` prints effective values. Exit codes 0/1/2/3 documented.
- **`ntx gold progress` / `ntx gold diff`** — annotation progress by stratum
  against the frozen frame, and claim-level differences between annotators.
- **Performance** — batch inserts make the 119-document frame ≈1.8× faster
  (0.71 s, ≈169 docs/s).

## Not in this release

- Human gold v2 (30 documents, double annotation, adjudication) is still pending,
  so no v2 accuracy metric is claimed.
- Docker image and Zenodo DOI require a machine with Docker and a public remote.
- An LLM extractor remains a deferred, opt-in v0.4 idea (ADR 0002).
