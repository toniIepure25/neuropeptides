# ntx v0.17.0

First sanitized public release of `ntx`, a provenance-first evidence
surveillance system for neuropeptides and neurotrophic claims.

## Highlights

- **Text-free public gold.** `ntx gold redact` replaces verbatim sentences and
  surfaces with SHA-256 hashes while preserving labels and exact spans.
  `ntx gold hydrate` restores text from a local corpus and verifies every hash.
- **Evaluation guard.** `ntx eval` refuses redacted gold instead of silently
  scoring labels without text.
- **Redistributable demo.** The bundled corpus is restricted to 18 Europe PMC
  records with an explicit CC BY licence, with per-record attribution.
- **Release integrity.** `scripts/check_release.py` checks version, citation,
  changelog, release notes, repository URLs, PEP 561 typing and demo attribution.
- **Professional repository surface.** README rewrite, contribution guide, code of
  conduct, issue/PR templates, Dependabot, security policy and a tag-driven
  release workflow with checksums.

## Compatibility

- Python 3.11–3.13.
- Database schema v8, report schema v4, quality payload v2, ledger export v3.
- Annotation schema v2; redaction adds optional hash fields only.
- Runtime remains Python standard library only.

## Data changes

The public tree no longer contains verbatim gold sentences or mixed-licence demo
abstracts. `data/private_gold/pilot_annotations.json` is local-only. The full corpus remains
git-ignored under `data/`.

## Verification

- Full test suite with line ≥93%, branch ≥85% and combined ≥90% coverage.
- Ruff, format, mypy, release-metadata check.
- Redact → hydrate round-trip with tamper detection.
- Clean-wheel install, offline demo, `ntx check`, `ntx quality`, `ntx doctor`.
- Two reproducible builds with `SOURCE_DATE_EPOCH=1794680589`.
- Artifact checksums are published as `SHA256SUMS` on the release.

## Known limitations

There is no human-validated gold set and no DOI yet. Effect sizes are heuristic
and not pooled. This is research software, not a clinical decision tool.
