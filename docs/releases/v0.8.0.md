# ntx v0.8.0 — 2026-11-14

Explicit generation: precursor proteins can be digested with named rules, candidate
analogs can be enumerated with two bounded operations, and every generated
sequence carries append-only lineage. This release does not rank molecules or
predict activity, and a cleavage pattern is not a claim about biology in vivo.

## Highlights

- **Schema v5.** New `precursors` and `candidate_lineage` tables with indexes and
  `UPDATE`/`DELETE` triggers. A v4 database migrates in place.
- **`ntx precursor import|list|show`.** Transactional JSONL/JSON import; canonical
  residues; length 2–10,000; optional UniProt/source/notes; content-derived
  `PR-...` ids; UTF-8 BOM support; duplicate rejection.
- **`ntx generate cleavage`.** Trypsin, chymotrypsin, Lys-C, Arg-C and Glu-C
  rules, all with a proline exception; `--missed` enumerates joined digest
  segments; min/max length filters; hard `--max-candidates` cap that fails rather
  than truncating.
- **`ntx generate analogs`.** N/C truncations (keeping at least two residues) and
  single alanine substitutions; the target is inherited, modifications and
  hypothesis association are not; hard `--max-variants` cap.
- **`ntx candidate lineage`.** Deterministic `L-...` records with source, parent,
  operation, span, enzyme/missed setting, all observed sites and parameters.
- **Export schema v2.** Precursors and lineage are included in the ledger SHA-256
  content hash. Re-exporting the same ledger still gives the same hash.
- **`docs/GENERATION.md`.** Rules, operations, caps, idempotence, lineage and
  explicit non-claims.

## Not in this release

- Ranking, docking, MD, permeability, stability or immunogenicity prediction.
- Signal-peptide, propeptide or PTM-aware cleavage; pH/time/kinetics modelling.
- Automatic target assignment, hypothesis selection or preregistration.
- Double mutants, substitution matrices or combinatorial library design.
- Any claim that a generated peptide is novel, active, exposed or synthetically
  accessible.

Generated rows feed the same prediction ledger: a directional prediction must be
registered before the outcome, and a small ledger is descriptive, not calibrated.
