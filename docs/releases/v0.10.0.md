# ntx v0.10.0 — 2026-11-14

Descriptive calibration report: eligible ledger predictions can now be compared
with observed agreement through a reliability table, Brier skill, ECE/MCE, the
Murphy decomposition and a deterministic bootstrap interval. The report never
claims that the ledger is calibrated, that a prediction preceded an experiment or
that imported sources are authentic.

## Highlights

- **`ntx ledger calibration`.** Uses exactly the eligible rows of `ledger score`
  (latest outcome, QC pass/warn, decisive direction), so the two commands cannot
  silently disagree about inclusion.
- **Reliability table.** Equal-width probability bins from 0.5 to 1.0 (default 5,
  `--bins` 2–10), with mean predicted probability, observed agreement, absolute
  gap, bin Brier score and sparse-bin marking. Empty bins stay visible.
- **Aggregate metrics.** Brier, skill versus 0.25, accuracy with a 95% Wilson
  interval, ECE, MCE and the binned identity
  `Brier = reliability - resolution + uncertainty`.
- **Deterministic bootstrap.** Percentile 95% intervals for Brier and ECE when
  `n >= 10`, with fixed bin edges, seed 0 and 500 resamples by default
  (`--bootstrap`, 0 disables).
- **Guardrails by construction.** `descriptive_only` is always true;
  `underpowered` is true below 10 eligible observations. Sparse bins and the
  exchangeability caveat are reported rather than hidden.
- **No schema or export change.** The database remains v6 and the ledger export
  remains `ntx-ledger-v3`; calibration is computed from existing rows.
- **`docs/CALIBRATION.md`.** Formulas, command, JSON fields, bootstrap caveat,
  safe/unsafe interpretations and explicit non-goals.

## Not in this release

- Proof that a prediction preceded an experiment, trusted registration time or
  external source verification.
- Cluster bootstrap, correction for selective reporting or multiple comparisons.
- A rubric probability, replication probability, treatment effect or candidate
  ranking.
- Any claim that a small or selectively reported ledger is calibrated.

The report is a description of the rows that exist. It is the input to a future
calibration discussion, not a conclusion.
