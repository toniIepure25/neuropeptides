# ntx v0.4.0 — 2026-11-13

Gold-ready evaluation, refreshed model drafts, annotation operations and full
local CI parity. Rules-only core: no model downloads, no network in the default
path. No human gold metric is claimed.

## Highlights

- **Role-aware evaluation.** `ntx eval` reports role-strict claim P/R/F1,
  `role_gold_coverage`, role accuracy on strict matches and role-mismatch
  examples. When gold has no roles, coverage is 0 and the role score is not
  interpretable — the report says so instead of presenting a misleading number.
- **Deterministic error attribution.** Every strict claim FP/FN is classified as
  `entity_mismatch`, `outcome_mismatch`, `direction_mismatch`, `span_mismatch`
  or `sentence_mismatch`, with capped examples; a role-strict bootstrap CI is
  added when gold roles exist. This turns a single F1 into a work queue.
- **JSON-only machine output.** `ntx eval --json`, `ntx synthesize --json` and
  `ntx ablate --json` write one JSON document to stdout; human reports are never
  mixed in.
- **Offline draft replay.** `scripts/build_gold_v2.py --from-corpus` rebuilds
  `gold/v2/draft.jsonl` from the frozen frame and local corpus with no network,
  fails clearly when the corpus is missing, and is byte-identical on rerun.
- **Draft v0.3.** 119 documents / 141 claims (139 intervention, 2 comparator),
  now with role, section, evidence span, resolver and reasons. It remains a
  model draft, explicitly **not** gold.
- **`ntx gold conflicts`.** Extracts field-level disagreements and writes a blank
  adjudication skeleton (`value_a`/`value_b`). Blank rows are unfinished, so
  `gold merge` ignores them rather than overwriting labels with empty values.
- **`ntx audit sample`.** Deterministic role/design-stratified worksheet with
  sentence and evidence span for manual precision review while human gold is
  incomplete. It never reports precision on its own.
- **Annotator validation.** The browser tool shows section/evidence, checks span,
  sentence, enumerations and evidence containment, and exports the new fields.
- **CI parity locally.** `scripts/ci.ps1` builds sdist+wheel, installs the wheel
  into a fresh venv outside the repository, runs `demo`/`check`, and verifies
  byte-identical frozen reports.

## Not in this release

- Human gold v2 (30 documents, double annotation, adjudication) is still pending,
  so no v2 accuracy metric is claimed. `role_gold_coverage` will be 0 until that
  exists.
- Docker image and Zenodo DOI require Docker and a public remote, which this
  environment does not provide.
- An LLM extractor remains a deferred, opt-in idea (ADR 0002).
