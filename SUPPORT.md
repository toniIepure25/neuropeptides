# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/toniIepure25/neuropeptides/discussions)
for usage questions, ideas and show-and-tell. Include the `ntx --version`, Python
version, operating system and the exact command.

## Bug reports

Open an issue with the bug template and include:

- a minimal command or corpus that reproduces the problem;
- the expected and actual behaviour;
- whether the failure involves provenance, licensing or a security boundary.

Do not attach abstracts, full text or private annotation files. Use a synthetic
or redacted example.

## Security reports

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Data and licensing questions

See [docs/DATA_GOVERNANCE.md](docs/DATA_GOVERNANCE.md). The project cannot grant
rights to third-party text or decide whether a local corpus is licensed for your
use.

## Scope

This is research software. Support does not include clinical interpretation,
medical advice or validation of a user's scientific conclusion.
